# Light-based-Tripwire-Alarm-System

My goal with this project was to create a light based tripwire alarm system to explore the use of phototransistors and flashing LEDS.

 The circuit detects changes in light when the light aimed at the phototransistor is broken by someone passing through or obstructing it. Upon this, The LED flashes and the buzzer sounds on and off to signal an intruder. 


 Bill of Materials (BOM):
 - Arduino Uno R3 Board
- Red LED
- Buzzer
- Phototransistor
- Resistor (10k Ohms)
- Resistor (220 Ohms)
- Laser/Light Source

Should you choose to make this project, please excuse the very unpolished hand drawn circuit diagram.
